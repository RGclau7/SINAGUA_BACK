# SINAGUA — backend

API Laravel 13 (PHP 8.3) con autenticación JWT (HS256, firebase/php-jwt) y bcrypt, spatie/laravel-permission, PostgreSQL, MinIO y una cola con worker.

- Contrato OpenAPI 3.1: [docs/api/openapi.yaml](docs/api/openapi.yaml) · Swagger UI en `/docs`
- Postman: [docs/postman/](docs/postman/)
- Seguridad, concurrencia y memoria: [docs/API-SEGURIDAD-CONCURRENCIA.md](docs/API-SEGURIDAD-CONCURRENCIA.md)

Cómo levantarla, endpoints y contrato de sincronización: ver el [README de la raíz](../README.md).
